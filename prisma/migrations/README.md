# Prisma migration gate

The repository intentionally does **not** contain a hand-written baseline migration. The baseline must be generated by Prisma from `prisma/schema.prisma` in an environment where project dependencies are installed, then reviewed and committed before the first production deployment.

Generate and validate it against an empty development database:

```bash
pnpm install
pnpm db:generate
pnpm db:validate
pnpm prisma migrate dev --name baseline
pnpm build
pnpm test
```

Then test deployment against a second empty PostgreSQL database:

```bash
DATABASE_URL='<empty-test-database>' pnpm prisma migrate deploy
```

Only after that migration is committed should `docker compose -f docker-compose.prod.yml up --build -d` be used for production.
